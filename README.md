# Arche — 아르케

Windows 데모 배포 저장소입니다.

## 다운로드

[Releases에서 Windows 버전 받기](https://github.com/aister9/Arche-releases/releases)

원하는 버전의 `Arche-…-win64.zip`을 내려받아 압축을 해제한 뒤 `Arche.exe`를 실행하세요. Windows 64비트용이며 별도 설치가 필요 없습니다.

버전별 변경 내용은 각 릴리스 노트에서 확인할 수 있습니다. 함께 제공되는 `.sha256` 파일로 다운로드 무결성을 확인할 수 있습니다.

이 저장소는 배포 파일과 릴리스 노트용입니다. 게임 개발 소스는 포함하지 않습니다. GitHub가 자동 생성하는 **Source code** 압축 파일 대신 **Windows ZIP**을 받으세요.

현재 개발 중인 데모이며 실행 파일에는 코드 서명이 없습니다. 게임 및 에셋의 권리는 별도 허가가 없는 한 권리자에게 있습니다. 엔진과 제3자 구성 요소의 고지는 배포 ZIP의 `THIRD-PARTY-NOTICES.txt`를 확인하세요.
